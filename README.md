The website features a product store with CRUD operations for the user, cart, and product as well as user authentication. It utilizes the API from fakestoreapi. Once the user is authenticated, they can access the listing in the sidebar and manage the items with the table actions or modals.

Key Features

Product Page

* CRUD Operation
* Product list includes description,rating and image
* Search by product name and sorting

Carts Page

* CRUD Operation
* Formatted Table Listing 
* Search by User name or email

Users Page
* CRUD Operation
* Formatted Table Listing
* Search by User name, email, mobile or username.

Login

* Only created users can access the website
* Logout
